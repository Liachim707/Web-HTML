# Image Gallery

Учебный проект — простая HTML-страница с галереей случайных изображений.

## Что делает проект

- Отображает галерею из четырёх изображений.
- Загружает изображения с сервиса [Picsum Photos](https://picsum.photos/).
- По нажатию на ссылку **New images** перезагружает страницу, чтобы получить новый набор изображений.
- Показывает подпись автора: **Random image app by Michael**.

## Используемые технологии

- HTML5
- CSS (файл стилей `styles.css` находится в проекте)

## Как запустить проект

### В CodeSandbox

1. Откройте проект в [CodeSandbox](https://codesandbox.io/).
2. Импортируйте репозиторий GitHub или откройте уже созданный sandbox.
3. Откройте файл `index.html` и запустите предпросмотр (Preview).

### Локально на компьютере

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Liachim707/Web-HTML.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd Web-HTML
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите локальный сервер:

   ```bash
   npm start
   ```

5. Откройте адрес, который появится в терминале (обычно это локальный адрес, например `http://localhost:3000`).
