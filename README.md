# Web-HTML

## Описание проекта

Web-HTML — простая HTML-страница с галереей случайных изображений.

## Что делает проект:

- Отображает галерею из четырёх изображений.
- Загружает изображения с сервиса [Picsum Photos](https://picsum.photos/).
- По нажатию на ссылку **New images** перезагружает страницу, чтобы получить новый набор изображений.
- Показывает подпись автора: **Random image app by Michael**.

## Используемые технологии

- HTML5
- CSS 

## Как запустить проект

### В CodeSandbox

1. Откройте проект в [CodeSandbox](https://codesandbox.io/).
2. Импортируйте репозиторий GitHub или откройте уже созданный sandbox.
3. Откройте файл `index.html` и запустите предпросмотр (Preview).
